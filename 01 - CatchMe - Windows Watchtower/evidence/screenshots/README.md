# Supplied Screenshot Evidence

This directory contains screenshot copies supplied for Windows Watchtower. `EV-01`–`EV-17` are the earlier THM-PC Security/Sysmon/PowerShell screenshots. `EV-18`–`EV-29` are the additional initial-access overview, RDP, phishing and USB screenshots.

Screenshots have been copied without intentional image edits. Descriptive filenames are analyst labels; consult `../evidence-register.md` for interpretation and limitations. Screenshots are not raw event records and should not be used as the only basis for a final incident determination.
